# Wiznotes_tools: Скрипты для пакетной обработки заметок WizNote

## Введение

Я пользуюсь WizNote с 2012 года и накопил более десяти тысяч заметок, но в итоге решил расстаться с этим сервисом — несмотря на то, что моя VIP-подписка была оплачена вплоть до 2030 года.

Когда-то я был в восторге от обновленного WizNote, в котором появились поддержка Markdown с предпросмотром в реальном времени и базовые функции двусторонних ссылок; это были одни из лучших моментов в истории сервиса. Однако за этим последовали годы медленных обновлений и постоянного отсутствия фундаментальных функций. Фактически мне пришлось стать «пользователем двух версий», вынужденным одновременно использовать и старую, и новую редакции программы. Справедливости ради стоит отметить, что основа WizNote по-прежнему надежна: инструменты для сохранения веб-страниц (web clipping), поддержка Markdown и API остаются вполне функциональными. Вероятно, именно поэтому я так долго ждал улучшений.

В конце концов, чаша терпения переполнилась. Проблемы с удобством использования, о которых я сообщал в службу поддержки, так и не были решены, а сам продукт практически не обновлялся последние два года, из-за чего я полностью утратил к нему доверие. Ситуацию усугубила ужасная работа веб-версии после перехода на смартфон с HarmonyOS в этом году, а также недавние сбои, при которых даже изображения не отображались при сохранении статей из WeChat. В итоге я твердо решил отказаться от WizNote.

К счастью, одной из главных причин, по которой я изначально выбрал WizNote, были открытость сервиса и возможность легкого переноса данных. Воспользовавшись свободным временем в выходные, я написал скрипт для пакетного экспорта, позволяющий практически идеально выгрузить весь мой архив заметок — достойный способ попрощаться с сервисом.

Прощай, WizNote. Спасибо, что был со мной последние 13 лет!

## Основной инструмент: get_wiz_notes.py — Пакетный экспорт заметок WizNote через Web API

Поскольку официальный клиент WizNote не поддерживает пакетный экспорт, этот скрипт использует Web API сервиса для массовой выгрузки заметок (включая поддержку изображений и вложений). ### 🎯 Ключевые возможности

- **🚀 Автоматическая обработка больших папок**: Автоматическое обнаружение и обработка папок, содержащих более 1000 заметок; получение полного списка осуществляется с помощью двусторонних запросов и интеллектуальной дедупликации.
- **📂 Пакетный экспорт по папкам**: Поддержка пакетного экспорта заметок с разбивкой по папкам и их унифицированного преобразования в формат Markdown.
- **🔄 Поддержка различных форматов**: Поддерживается экспорт заметок в устаревшем формате HTML, в новом формате Lite Markdown, а также заметок для совместной работы.
- **📝 Полные метаданные**: Экспортируются метаданные заметок, включая время создания, время изменения, теги и многое другое.
- **⏸️ Возможность возобновления**: Поддерживается возобновление экспорта; процесс можно прервать и продолжить в любой момент.
- **📊 Подробное протоколирование**: Ведется детальный журнал для отслеживания процесса экспорта.
- **🔗 Сохранение ресурсов**: Автоматическая загрузка и сохранение файлов ресурсов (например, изображений и вложений), встроенных в заметки.
- **⚡ Параллельная обработка**: Поддержка многопоточного параллельного экспорта (по умолчанию — 10 потоков; перемешивание записей в журнале — нормальное явление) для повышения эффективности. ### 🏗️

### 🚀 Использование

#### 1. Установка зависимостей
```bash
pip install -r export_wiznotes/requirements.txt
```

#### 2. Настройка учетных данных
Создайте файл `.env` в корневой директории проекта (см. `.env.example`):

```env
WIZ_USERNAME=your_email@example.com
WIZ_PASSWORD=your_password
```

#### 3. Генерация списка папок
```bash
cd export_wiznotes
python get_folders_and_notes_list.py
```
В зависимости от параметров конфигурации можно сгенерировать:
- `./output/WizNote_Directory.log` — список папок (по умолчанию)
- `./output/folders & notes.txt` — подробный перечень заметок

#### 4. Пакетный экспорт заметок

Пакетный экспорт заметок выполняется на основе файла списка папок `./output/WizNote_Directory.log` (можно вручную отредактировать этот файл, чтобы управлять областью экспорта). 
```bash
cd ..  # Вернуться в основной каталог
python get_wiz_notes.py
```

#### 5. Сравнение экспортированных заметок (необязательно)

1. Запустите `get_folders_and_notes_list.py` для экспорта списка **онлайн-заметок** (`./output/folders & notes.txt`);
2. Запустите `get_exported_mdfiles.py` для получения списка **локальных заметок**, которые уже были экспортированы (`./output/exported_md_files.txt`);
3. Запустите `compare_notes_in_folders.py` для автоматического сравнения двух списков и создания файла с различиями (`./output/compare_diff.txt`); вручную проверьте, все ли заметки были экспортированы, и обработайте оставшиеся исключения, экспортировав их вручную.

### 🌐 Режим веб-интерфейса (рекомендуется)

Помимо интерфейса командной строки, этот проект предлагает веб-интерфейс (Web UI) для более интуитивного и удобного использования.

#### Как начать работу

```bash
# Установка дополнительных зависимостей
pip install -r web/requirements.txt

# Запуск веб-сервиса
python web/app.py
```

После запуска перейдите по адресу http://127.0.0.1:8000 для доступа к пользовательскому интерфейсу. #### Обзор функций

- **Вход в систему**: Поддержка ручного ввода учетных данных или их автоматического заполнения из файла `.env` с помощью кнопки «Load from config» (Загрузить из конфигурации).
- **Просмотр папок**: Просмотр полной древовидной структуры папок WizNote после входа в систему.
- **Пакетный экспорт**: Экспорт выбранных папок одним нажатием; отслеживание хода экспорта и просмотр логов в реальном времени.
- **Статистика и сравнение**: Сканирование локально экспортированных заметок и их сравнение с заметками в облаке для выявления отсутствующих элементов.
- **Управление конфигурацией**: Настройка таких параметров, как директория экспорта и количество параллельных потоков, непосредственно на странице.

### ⚙️ Расширенная настройка

#### Пример пользовательского использования
```python
from export_wiznotes import WizNoteClient, NoteExporter, setup_logging

# Настройка логирования
setup_logging("./export_wiznotes/output")

# Создание клиента (считывает конфигурацию учетной записи из файла .env в корне проекта)
client = WizNoteClient()
client.login()

# Создание экспортера
exporter = NoteExporter(client)

# Экспорт заметок из определенной папки
exporter.export_notes(
folder="/My Drafts/",
export_dir="./export_wiznotes/output",
resume=True  # Включение возобновления с места остановки
)
```

#### Настройка параллельной обработки
Изменение параметров параллельной обработки в файле `get_wiz_notes.py`:
```python
max_workers = 10  # Количество параллельных потоков; настраивается в зависимости от условий сети
```

## Другие скрипты (архив)

### **clipboard_wxnotes_yagmail_wiz:** извлекает ссылки (на статьи из официальных аккаунтов WeChat, Toutiao, Xiaohongshu, веб-страниц и т. д.) и другой контент из текста в буфере обмена, а затем пакетно сохраняет их в WizNote.

Из-за изменений в API WeChat процесс сохранения статей из официальных аккаунтов стал гораздо более трудоемким. Я написал этот скрипт автоматизации, чтобы повысить эффективность работы.

Мой текущий рабочий процесс сохранения статей из WeChat (или таких источников, как Toutiao) выглядит следующим образом:

1.  Держите запущенным в фоновом режиме на телефоне приложение для расширения возможностей буфера обмена (например, «Jianzhidui» / 剪纸堆);

2.  Увидев интересную статью в официальном аккаунте WeChat, выберите в меню пункт «Скопировать ссылку»;

3.  Если вы не хотите сохранять статью целиком, можно выделить и скопировать отдельные абзацы; это работает не только со статьями из WeChat — в буфер обмена можно копировать текст из любого приложения для чтения;

4.  Спустя некоторое время (например, через неделю) соберите весь контент, сохраненный в фоновом режиме приложением «Jianzhidui», и экспортируйте его в виде текстового файла;

5.  Запустите этот скрипт автоматизации, чтобы извлечь из текста ссылки на статьи WeChat и сохранить все статьи в WizNote по электронной почте; контент, не относящийся к ссылкам WeChat, объединяется и сохраняется в WizNote отдельно;

### **image2wiz_by_yagmail.py:** Пакетная отправка изображений и распознанного текста (OCR) из них в WizNote.

Я часто делаю скриншоты интересного контента на телефоне, но сталкиваюсь с проблемой: потом их невозможно найти через поиск. В отличие от Evernote, сервис WizNote не поддерживает поиск текста внутри изображений.

Чтобы решить эту задачу, я сначала использую сервис распознавания текста (OCR) от Baidu на базе ИИ для массового преобразования скриншотов в текст. Затем с помощью этого скрипта я отправляю скриншоты и распознанный текст в WizNote, где автоматически создается заметка. Это делает возможным поиск по содержимому. В результате информация со скриншотов не теряется — я могу найти и просмотреть её в любой момент.

**check_undone_imgs.py:** Выявляет файлы, которые не удалось отправить в WizNote, и перемещает их обратно в папку «ожидающих отправки» (pending).

Со временем у меня накопились тысячи изображений; я сохраняю их в WizNote, отправляя пакеты файлов по электронной почте. Поскольку почтовые сервисы ограничивают количество писем, отправляемых за сутки, иногда кажется, что письмо ушло успешно, хотя на самом деле это не так. Я написал этот скрипт, чтобы находить такие неудачные отправления и повторно отправлять их на следующий день.
